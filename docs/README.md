# docs — 팀 코드 저장소용 기획 문서 사본

이 폴더는 옵시디언 PM 볼트에서 **코드를 짤 때 실제로 참고해야 하는 "계약" 성격 문서 5개만** 골라 복사해온 것입니다. 나머지 기획/PM 문서(WBS, 체크리스트, 회의록, 일일업무일지, NQNQ 브랜드 기획 등)는 볼트에만 있고 이 저장소로는 옮기지 않습니다 — 매일 바뀌는 PM 내부 관리용 문서까지 복사하면 금방 낡은 사본이 되기 때문입니다.

**이 폴더의 문서는 스냅샷입니다.** 실시간 최신본은 항상 옵시디언 볼트 쪽이 원본이고, 여기는 팀원이 코드 작업 중 참고하는 용도로 주기적으로만 갱신됩니다. 문서 내용에 변경이 필요하면 볼트에서 먼저 고치고 PM(나경)에게 알려주세요 — 다음 동기화 때 반영됩니다.
